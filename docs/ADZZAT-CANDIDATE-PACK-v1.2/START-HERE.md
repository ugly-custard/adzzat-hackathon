## Before the clock starts
Install Python 3.10+ and the starter requirements, verify the example files, and confirm access to your own preferred AI tools/subscriptions. Setup checks do not authorise starting the assessment early. Ask the event host about access needs, equipment or setup problems privately.

The host confirms the submission destination, support contact, the bring-your-own-AI policy, showcase roster, participation/expense terms and hiring timeline before the assessment starts. Adzzat provides no API keys or AI subscriptions. Bring your own subscription/access for whichever AI tools you choose. No particular provider, paid tier or API access is required. Role location and compensation details are handled in the recruiting information, not inferred from this exercise.

## Submission
Submit a ZIP or private repository snapshot through the channel announced at kickoff. Name it CANDIDATE-ID_TRACK-A, TRACK-B or TRACK-C. Include README.md, CALIBRATION.md, CHANGE-RESPONSE.md and DECISIONS.md plus your track artefacts. Include a commit hash or immutable archive, exact run commands, dependency versions, seeds/model IDs and any outage incident reference. Keep credentials out. List incomplete items honestly.

After 15:00, judges assess the frozen snapshot. Any live edits occur on a disposable copy and count only toward the ownership check. Corrections to organiser materials or access incidents follow the shared incident policy.
